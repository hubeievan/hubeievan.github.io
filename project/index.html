我为APEC添光彩 · 南山少年城市探索｜项目过程文档

一、作品定位与主体思想

作品名称：我为APEC添光彩 · 南山少年城市探索。选题定位为城市名片类，以知识科普和少年行动形成交互闭环。

主体思想：以南山为窗口，用山海、人文与科创的3D城市探索，理解APEC的开放、创新与合作；让少年从观察家乡出发，写出自己的城市欢迎词。

面向青少年、来访者与作品评审。主路径为：城市地图 → 五站内部地图与故事 → APEC连接 → 知识挑战 → 探索册 → 个人城市名片。

二、页面功能与交互

城市探索首页：南山占开场视野约三分之二；福田、宝安、龙华、龙岗作为周边，通过拖动查看。南山南侧展现深圳湾海面与滨海跑道，深圳湾大桥连接香港。各区标注特色地标，城区道路与大桥设车辆往来。

地图支持拖动平移、右键旋转、滚轮或双指缩放、方向键平移、复位、昼夜切换、自动漫游、操作帮助及各页面的语音播报。标签、建筑和底部入口可进入五站详情；其他城区的地标可打开介绍。

五个主题子页面：APEC主题站、深圳湾、人才公园、南山科技园、南头古城。每站提供独立内部空间模型与六个观察点，共三十个观察点；支持3D/平面切换、选点、上一点/下一点、复位及返回城市首页。

总结播报：九个页面分别编写独立的中文导览，围绕主题、主要内容与探索收获进行总结；顶部可预览全文并播放、暂停、继续、停止及选择三档语速。地图观察点与城区建筑介绍可单独播报。页面总结不受地图拖动、课堂标签或挑战反馈更新影响，切换页面会停止旧播报。需要点击播放，声音由浏览器可用中文语音提供；不接入付费语音接口。

APEC小课堂：认识APEC、深圳2026、少年的行动三组内容；开放、创新、合作卡片链接对应南山站点，常见问题可展开查看。

知识挑战与探索册：答错可以重试，答对点亮徽章，五站进度同步。欢迎词可选择站点、填入参考句、自行编辑、复制及导出文本；仅在当前标签页保留草稿和进度。

三、开发思路与AI辅助编码使用说明

技术实现：使用React与TypeScript组织页面和数据，Three.js绘制可操作的3D场景，CSS实现响应式布局，浏览器会话存储记录挑战进度和欢迎词草稿。网站采用静态构建与线上部署。

AI使用方式：由使用者提出方向和纠正意见，AI辅助拆解需求、编写组件与模型代码、调整布局与交互，再根据反馈继续修订。AI辅助开发属于制作过程；本网站没有接入实时AI问答或文生图服务，欢迎词参考句来自本站内容。

迭代1：使用者要求铺满地图、以南山为主并连接香港。AI调整区域布局、开场视角、海岸、大桥和周边地标。

迭代2：使用者指出点击跳转与子页返回问题。AI统一使用直接页面链接，保留导航、面包屑和地图返回入口。

迭代3：使用者要求子页地图对应主体内部构造。AI将五站分别建模，补充观察点、3D/平面视角与布局解释。

迭代4：使用者要求各区车辆往来。AI添加城区与大桥车辆动画，并适配减少动态效果的系统偏好。

迭代5：根据参赛评分细则，AI强化首页APEC表达、五站议题连接、小课堂站点路线和个人欢迎词，并整理本过程文档。

迭代6：使用者要求浏览对应页面时有内容语音播报。AI建立共用语音控制与当前页面内容读取，加入观察点、建筑介绍独立播报，处理内容切换与旧语音取消，并验证播放状态与分段队列。

迭代7：使用者反馈逐段播报不可用，要求每页总结。AI为九个页面分别编写完整中文导览，取消自动拼接网页文字与页面更新触发的中断，保留独立点位讲解和页面切换停止机制。

核验方法：类型检查、生产构建、页面及内部链接检查；前期对地图视角、主题模型和车辆路径进行计算检查。本轮没有完成浏览器逐项实测、高清网页截图或录屏，需要按下方清单继续验收。

四、南山特色与原创设计思路

生态：用深圳湾海面、岸线、滨海跑道和观鸟空间体现山海城市；将守护海湾的小行动连接绿色发展。

科创：用腾讯滨海大厦双塔与连廊、中国电子总部等企业线索体现南山科创特色；学习任务从真实需求出发，讨论数字服务、AI信息核验与包容性。

人文：用南头古城城门、街巷、传统院落与创意空间表现历史与当代相遇；通过核实资料、尊重居民、向亚太朋友讲述家乡，理解开放交流。

公共空间：以人才公园的湖、步道、书吧和公共设施表现人才与梦想；思考不同背景的人怎样共享城市。

原创表达：将城市模型、空间观察、主题解读、知识徽章和个人欢迎词串为一条学习路径。建筑为程序绘制的教育模型；真实地标参考公开资料，空间位置和尺度为示意。APEC主题展馆及企业内部学习区为概念设计，不是实际会场或企业真实内部布局。

六、录屏演示路线

  1. 首页：介绍作品主线，拖动查看五区和香港，展示周边地标、车辆、海面和大桥；演示缩放、旋转、复位、昼夜、漫游、帮助与探索任务。
  2. 逐一进入五站：展示每站独立空间与六个观察点，演示3D/平面切换、选点、上一点/下一点及复位；讲解APEC连接，演示返回城市页。
  3. 语音：在首页、一个主题站和小课堂点击顶部总结播报，预览各自总结全文，演示暂停、继续、停止和语速；选择观察点单独播报，切换点位时确认旧点位讲解停止；播放整页总结时切换课堂标签，确认导览能继续；切换页面后播放新页面总结。检查手机与桌面浏览器声音。
  4. 挑战：演示一次答错重试，完成五站正确答案；查看导航计数与探索册进度同步。
  5. 小课堂：切换三组内容，展开常见问题，点击开放、创新、合作对应的城市站点入口。
  6. 探索册：展示徽章，选择城市窗口、使用参考句、改写欢迎词，演示复制与文本导出。
  7. 过程说明：查看功能、AI辅助开发迭代、南山设计与资料来源，演示文档下载或打印。录屏时长依比赛实际要求安排。
